# Gegenwart – Bausteine (Bundle)

`bundle.css` und `bundle.js` stammen unverändert aus dem Designsystem **Gegenwart** (Version vom 26.10.2026, Gruppen Interaktion, Daten, Orientierung, Lernbewegung). Die Farben laufen über Tokens (`--grund`, `--text`, `--petrol`, `--oxid`, `--kuli` …); jede Seite dieses Projekts setzt diese Tokens auf die Farben des GGK-Labors. Farben, Wortmarke und Metapher von Gegenwart wandern nicht mit – nur die Bausteine.

Erste Nutzung: `m23-die-gesellschaft.html` (Schieber, Zeitleiste, Wahl, Balken, Skala, Schalter »Weniger Bewegung«).
