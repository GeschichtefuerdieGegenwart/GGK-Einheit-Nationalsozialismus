Lehrkraftbereich verschlüsseln

Dieses Werkzeug läuft nur in Ihrem Browser. Nichts wird übertragen.

  1. Klartext-Datei wählen (z. B. m19-lehrkraft.html, nicht im Repository speichern).
  2. Langes Passwort eingeben (mind. 12 Zeichen, besser eine Passphrase aus 4–5 Wörtern).
  3. Die erzeugte Datei m19-lehrkraft.enc.json im Repository im Ordner lk/ ersetzen.
